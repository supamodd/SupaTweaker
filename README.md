# SupaTweaker

Современный твикер Windows для Visual Studio Insiders.

## Как открыть

1. Установите **.NET 8 SDK** и **Visual Studio Insiders** (нагрузка *Разработка классических приложений .NET*).
2. Откройте `SupaTweaker.sln`.
3. Запускайте **от имени администратора** (твики пишут в реестр и службы).

Страница активации Windows **не включена** — это незаконно.
