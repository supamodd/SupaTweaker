SupaTweaker — что создать в Visual Studio Insiders
=================================================

1. File → Open → Project/Solution → выберите папку SupaTweaker → SupaTweaker.sln
   или: File → New → Project from existing code.

2. Рабочая нагрузка: «Разработка классических приложений .NET» + SDK .NET 8.

3. Первый запуск: правый клик по проекту → Debug → Start as administrator
   (или всегда запускайте VS Insiders от администратора).

4. Build → Build Solution (Ctrl+Shift+B), затем F5.
